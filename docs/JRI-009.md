## Additive seeding and history

One `seed_searches` helper serves fresh setup, startup upgrades for every registered
source, and newly created custom sources. Startup now includes existing custom
sources; their catalog no longer remains stuck at its creation-time contents.

The helper inserts only missing exact `(source_id, phrase)` pairs, with both owner
flags false. It records each insertion in the same pass's existing-phrase set,
preventing duplicate inserts when a phrase appears in several groups. Existing
rows are never updated: IDs, exact spelling/case/whitespace, group assignment,
selected/configured flags and owner-specific phrases are preserved. For new rows,
the first catalog group wins; original groups precede the additions. For example,
`925 ring`, `jewelry jar` and `turqoise` keep their historical groups.

Source definitions, authorization, sample references/verification, last-import
timestamps and import history are untouched. No global search-pattern history or
observations are created by recommending or seeding a phrase. No schema migration
was needed. Existing same-source item deduplication retains separate query/message
observations, and the exact-query success gates are unchanged.

## Owner workflow

1. Open **Multi-Source Inbox → Saved search assistant**. Choose ShopGoodwill or HiBid.
2. Start with the 15 recommendations or choose the full catalog and a group.
3. Use **Copy exact phrase**, then configure the search yourself through the source's
   supported interface. If clipboard access is unavailable, the exact text is
   selected for manual copying. Sources may interpret word order, quotes, Boolean
   operators, stemming and misspellings differently.
4. Record your selected/configured status for that phrase. Saving returns to the
   same source, catalog view, group and search card. This records your action; it
   does not change an external account or verify an alert format.

Filters stack on narrow screens. A group that does not exist after switching
sources resets to All groups. Empty starter/group combinations have an explicit
message explaining how to broaden the view.
