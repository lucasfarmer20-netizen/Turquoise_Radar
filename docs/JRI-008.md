## Existing editor, completed

The existing listing editor now accepts `item_end_time` and `shipping_evidence`,
and labels `carrier` separately. The listing/workbench displays all three, with
Alaska fulfillment shown independently of quoted shipping and its amount status.
Evidence text never confirms a cost, carrier availability or destination eligibility.

New or changed deadlines must contain the full date/time and an explicit UTC offset
or `Z`, for example `2026-11-04T18:30:00-06:00`. The represented instant and offset
survive saving and revisiting. Natural-language notices, numeric timestamps and
new timezone-free deadlines are rejected with HTTP 422 before any mutation.
An unchanged historical timezone-free deadline remains editable and is visibly
labelled as lacking a timezone; unrelated edits do not invalidate it.

Omitted fields retain their values. Explicitly empty fields clear to UNKNOWN using
the editor's existing behavior. Each successful edit creates the existing audited
before/after record. Source observations, original messages, decisions, identities,
financial calculations and schema remain unchanged. No migration was introduced.
An auction-wide start-of-closing quote is not an individual lot deadline; ambiguous
wording stays in source/evidence text until a lot-specific deadline is known.

## Owner walkthrough

1. Open **Auction research**, choose a candidate and select **Send to purchase-review
   queue**. Existing reviewed candidates link directly to their workbench listing.
2. Select **Edit evidence & recalculate**. Enter the individual lot deadline with
   offset, the shipping evidence (source/reference, observation date, quote and
   restrictions), and the carrier. Set the shipping amount/status and Alaska
   fulfillment separately, only where supported.
3. Save and revisit **Current lot & shipping evidence**. Review the financial
   breakdown and unresolved costs. An accepted deadline or evidence note does not
   establish a safe bid or a buying decision.
4. Use **Identify this jewelry** to create/link a research case with permitted
   photographs, then **Continue in workbench**. A maker can remain UNKNOWN.
   Record defensible comparable sales through the existing comparable tools;
   actual owner decisions remain separate from research recommendations.
